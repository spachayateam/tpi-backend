# Backend de TPI - Spa

Este proyecto forma parte del Trabajo Práctico Integrador (TPI) y corresponde al desarrollo del backend para un sistema de gestión de turnos de un spa.

## Tecnologías utilizadas

- Node.js
- Express.js
- MySQL
- phpMyAdmin (para administración de la base de datos)
- node-cron (para tareas programadas como la reserva desde el calendario)
- nodemailer (para envios de comprobantes de turno al cliente)
